# Code of Conduct

## Our pledge

We pledge to make participation in this project a harassment-free experience for everyone, regardless of age, body size, disability, ethnicity, gender identity and expression, level of experience, nationality, personal appearance, race, religion, or sexual identity and orientation.

## Our standards

Examples of behavior that contributes to a positive environment:

- Using welcoming and inclusive language
- Being respectful of differing viewpoints
- Gracefully accepting constructive criticism
- Focusing on what is best for the community and for **user privacy**

Examples of unacceptable behavior:

- Trolling, insulting/derogatory comments, and personal or political attacks
- Public or private harassment
- Publishing others’ private information (including private note content) without permission
- Encouraging unauthorized access to systems or data

## Scope

This Code applies within project spaces (GitHub issues, PRs, discussions) and when representing the project publicly.

## Enforcement

Report unacceptable behavior via GitHub issues or the repository security contact path. Maintainers may remove, edit, or reject contributions that violate this Code, and may ban contributors for severe or repeated violations.
