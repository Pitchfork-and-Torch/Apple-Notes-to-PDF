# Apple Notes to PDF

**Exportieren Sie Apple Notes nach PDF, Markdown und HTML unter macOS — 100 % lokal, kein Cloud-Upload.**

Version **7.0.0** · MIT · [English README](../../README.md)

## Schnellstart
```bash
./export-apple-notes.sh --limit 5
./export-apple-notes.sh --format md,html --folder Arbeit
```
