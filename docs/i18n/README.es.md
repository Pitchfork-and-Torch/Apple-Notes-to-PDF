# Apple Notes to PDF

**Exporta Apple Notes a PDF, Markdown y HTML en macOS — 100% local, sin subida a la nube.**

Versión **7.0.0** · Licencia MIT · [English README](../../README.md)

## Inicio rápido
```bash
./export-apple-notes.sh --limit 5
./export-apple-notes.sh --format md,html --folder Trabajo
```

## Características
- PDF maestro + PDF por nota
- Markdown listo para Obsidian (YAML)
- HTML con búsqueda y modo oscuro
- Adjuntos e hierarchy de carpetas
- Exportación incremental
- Sin telemetría
