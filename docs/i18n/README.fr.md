# Apple Notes to PDF

**Exportez Apple Notes en PDF, Markdown et HTML sur macOS — 100 % local, sans envoi cloud.**

Version **7.0.0** · Licence MIT · [English README](../../README.md)

## Démarrage rapide
```bash
./export-apple-notes.sh --limit 5
./export-apple-notes.sh --format md,html --folder Travail
```

## Fonctionnalités
- PDF maître + PDF par note
- Markdown compatible Obsidian
- Archive HTML (recherche, thème sombre)
- Pièces jointes + hiérarchie
- Export incrémental
- Aucune télémétrie
