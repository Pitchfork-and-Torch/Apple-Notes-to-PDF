# Infographic design brief — Apple Notes to PDF v7

## Deliverables

1. **Landscape social** — 1200×675 (X/Twitter, LinkedIn)
2. **Square** — 1080×1080 (Instagram / profile shares)
3. Optional **story** — 1080×1920

## Visual story

**Title:** From Notes lock-in → Local freedom  

**Left panel (“Lock-in”)**
- Stylized Notes.app yellow pad, subtle chain/lock motif (not scary)
- Labels: “Trapped in one app”, “No bulk export”, “Formatting lost in copy-paste”

**Center flow**
- Arrow / pipeline: Notes.app → Rich HTML (Automation) → Multi-format export
- Small icons: shield (“on-device”), folder tree, paperclip

**Right panel (“Freedom”)**
- Cards/stack: Searchable PDF · Markdown (Obsidian) · HTML archive · Attachments
- Checkmarks: hierarchy preserved · incremental · offline

**Footer badge strip**
`100% local  ·  MIT  ·  Free forever  ·  macOS 12+`  
`github.com/Pitchfork-and-Torch/Apple-Notes-to-PDF`

## Style

- Dark navy background `#0b1220`, accent blue `#5b9dff`, mint `#34d399`
- Clean geometric sans; high contrast; no cluttered stock photos
- Accessible: large type, not solely color-dependent

## Image generation prompt (copy-paste)

```
Professional tech infographic, 1200x675, dark navy background #0b1220.
Left: yellow Apple Notes pad with subtle lock icon labeled "Lock-in".
Center: glowing pipeline "Notes → Rich HTML → Export" with privacy shield.
Right: stack of export cards "Searchable PDF", "Obsidian Markdown", "HTML Archive", "Attachments".
Footer badges: "100% local · MIT · Free forever · macOS 12+".
Modern flat geometric style, blue #5b9dff and mint #34d399 accents, crisp typography, high contrast, no logos of other brands, no photoreal faces.
```
